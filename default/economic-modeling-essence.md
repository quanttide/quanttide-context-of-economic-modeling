# 经济建模的本质

记录于 2026-08-09（qtcloud-econ 建设反思）。

## 本质：经济建模是"逆向工程人性"

机制设计不是预测人、不是优化系统，而是**从期望结果反推规则**：给定想要的状态（招到留得住的人、招聘变收益），设计一套规则，让每个人**在自利的前提下**不得不走向那个状态。

- 逆向工程：先定结果 → 再反推规则 → 让系统自己收敛
- 结果不是选出来的，是**规则逼出来的**

招聘博弈实例：不直接"筛选人"，而是设计"池子 + 自找题 + 三层分类 + 转化路径"的规则，让理想型自证、白嫖者无处藏身且被转化。

## 三个深层本质

### 1. 人不是给定的，是规则塑造的

学院派假设类型外生固定；真实机制里，白嫖者可以变成付费客户——**规则有教育性，它塑造人**。

- 设计规则 = 设计人的行为空间和演化方向
- 类型不是筛选的前提，是规则的产物

### 2. 约束不是硬边界，是设计变量

- 缺钱？创造内部货币（培训额度）——边际成本近零、对方价值极高，预算约束被机制本身放松
- 缺信息？设计昂贵信号让伪装者无利可图
- **真正的约束从来不是资源，而是有没有跳出"约束给定"的假设**

### 3. 价值重构先于效率优化

- 学院派：给定系统求最优
- 创业者：重新定义系统边界——不优化"招聘成本"，重构成"价值交换系统"（每次互动都产生正向价值）
- **效率优化在系统内，价值重构在系统上**
- 设计者与科学家的分野：跳进系统内当建筑师，而非站在系统外当观察者

## 为什么招聘博弈是教科书级案例

同时展示三者：
- **类型可塑**：白嫖者 → 实训基地付费用户
- **约束内生**：用培训额度（内部货币）而不是现金
- **系统重构**：招聘从成本项变收益项，且给课堂导流——一个机制解决激励、预算、生态三个问题

## 一句话

**经济建模 = 用规则设计人的行为环境：结果不是选出来的，是规则逼出来的；人、资源、约束都是可设计的变量——设计规则的本质，是在设计人性本身。**
